# Resort Ledger Management System

A comprehensive resort management system for tracking bookings, payments, expenses, and analytics.

## Features

- **Room Management**: Track room inventory and availability
- **Booking System**: Manage reservations with multi-room support
- **Payment Tracking**: Record and monitor all payment transactions
- **Expense Management**: Track daily expenses with categorization
- **Analytics & Reports**: View detailed reports and export to Excel
- **Cash Reconciliation**: Daily cash closing with automatic calculations

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
